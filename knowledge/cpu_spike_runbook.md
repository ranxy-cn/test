# CPU 飙高排查手册

文档编号：RB-CPU-001  
适用系统：订单系统  
审核状态：已审核入知识库

## 适用条件

- 主机 CPU 持续高于 85% 达到 5 分钟
- 目标为无状态应用节点（非数据库）

## 排查步骤

1. 查看最近 30 分钟 CPU / 内存 / 磁盘曲线，确认是否单进程打满。
2. 读取应用错误日志（最多 100 行），出口必须脱敏（密码、Token、密钥打码）。
3. 核对最近发版或配置变更；若发版后出现 Full GC，优先怀疑内存泄漏。
4. 检查依赖：数据库连接、锁等待、上游接口是否正常。数据库异常时禁止重启应用。
5. 30 分钟内若已重启过，禁止再次重启，立即升级。

## 候选预案

- 根因命中「Full GC / 内存泄漏 / 发版后无状态进程卡死」→ `ACT-ROLLING-RESTART`
- 根因命中「复制延迟 / 主库故障」→ `ACT-DB-FAILOVER`（高风险，需审批）
- 未命中预案 → 输出排查报告并升级人工，不得临场发明命令

## 成功判据

业务登录与查询探测连续 3 次通过；观察期 CPU 回落且无复发。

## 停止条件

探测失败或复发：停止，不循环重启，携带证据链升级。
